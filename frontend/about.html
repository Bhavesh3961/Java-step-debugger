📖 What is Java Step Debugger?

Inspired by educational execution visualizers like PythonTutor, Java Step Debugger enables students, educators, and developers to write or paste any Java code and understand its exact runtime control flow.

Instead of guessing what happens inside loops, recursion, or array manipulations, the visualizer captures every execution step directly from the Java Virtual Machine. You can scrub through time using an interactive slider or step line-by-line using keyboard shortcuts.

✨ Key Features

🎯 Exact Line-by-Line Cursor Active execution indicator (▶) points to the current line with smooth auto-scroll keeping focus in a single screen.
📊 Real-Time Variable Table Inspects local variables, method arguments, arrays, and custom object fields at every instruction step.
⌨️ Standard Input (stdin) Dedicated input bar supports Scanner(System.in) and BufferedReader without hanging or timeouts.
📦 All Java Standard Libraries Pre-configured with java.util.*, java.io.*, java.math.*, java.time.* collections and data structures.
🔄 Recursion & Call Stacks Tracks recursive functions like Factorial with multi-frame stack visualization and return value inspection.
⚡ Keyboard Controls Use arrow keys or spacebar for rapid stepping, auto-playback, and scrub slider navigation.
