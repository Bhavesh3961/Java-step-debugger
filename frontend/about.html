🚀 What makes JavTrace different

⚡

Zero Server Latency & 100% In-Browser

Never wait in server queues or deal with cold starts. JavTrace parses and simulates execution directly on the client. It works everywhere—Mac, Windows, Linux, Chromebooks, and even mobile browsers—completely offline-ready.

💻

Integrated Execution Block

Type or paste Java code directly into the execution canvas. Includes smart 4-space auto-indent on Enter, natural brace typing, and zero cursor drifting.

🔍

Live Variable Inspector

Inspect stack variables, arrays, primitives, and method frames. Every line step highlights updated values with immediate visual diff cues.

🛡️

Infinite-Loop Circuit Breaker

Accidentally wrote while(true) without a break? The safety engine limits execution traces to 10,000 steps without ever freezing your tab.

⌨️

Full Scanner & stdin Support

Dedicated standard input stream for interactive algorithmic problems. Feeds integers, tokens, and multi-line strings cleanly into Scanner.

⚙️ How It Works

From source code to step-by-step visual frames in under 15 milliseconds.

Step 01 Input & Tokens Accepts custom Java code and standard input (stdin).
Step 02 AST Normalization Strips class boilerplate, handles Java integer division and loop syntax.
Step 03 Step Recording Captures call stack snapshots, variable states, and console buffers on every executed line.
Step 04 Interactive Scrubber Allows bi-directional time-travel stepping with the slider and arrow keys.
