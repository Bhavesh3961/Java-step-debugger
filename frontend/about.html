📖 What is Java Step Debugger?

Inspired by educational execution visualizers like PythonTutor, Java Step Debugger lets students, educators, and developers write or paste any Java code and understand its exact runtime control flow.

Instead of guessing what happens inside loops, recursion, or array manipulations, the visualizer captures every execution step directly from the Java Virtual Machine using JDI step events. You can scrub through time with an interactive slider or step line-by-line with keyboard shortcuts — all in one focused, non-scrolling screen.

✨ Key Features

🎯 Line-by-Line Cursor Active ▶ indicator tracks the executing line with smooth internal auto-scroll, keeping everything on one screen.
📊 Real-Time Variables Inspects local variables, method args, arrays, and custom object fields at every single step.
⌨️ stdin Support Dedicated input bar lets programs using Scanner(System.in) run without hanging or timing out.
📦 Full Standard Libraries Pre-configured with java.util.*, java.io.*, java.math.*, java.time.* — no missing imports.
🔄 Recursion & Call Stack Multi-frame stack visualization for recursive methods like Factorial, Fibonacci, and DFS.
🖥️ Single-Screen Layout Code, variables, output, and controls always visible on screen — no jumping up and down the page.
🎚️ Timeline Scrubber Jump to any execution step instantly using the interactive blue slider bar.
🔍 Syntax Highlighting Colour-coded Java keywords, types, strings, numbers, and comments for easy reading.
